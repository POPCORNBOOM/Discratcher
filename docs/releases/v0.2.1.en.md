- The hologram page is now a designer: each design is a folder you save and open, with recent designs on the start page. A new-design wizard asks for the lamp first (side light suits models, light from above suits colour pictures), then a template to start from.
- Positions can hold flat pictures: colour pictures are solved for the colour both eyes see, rainbow pictures are carved by lightness. Each colour picture has its own colour fidelity.
- All-angles positions: every part of the disc shows true colour as it turns past where you look, so the disc can be turned freely under a still lamp. New whole-disc colour picture template.
- Pictures can wrap round the ring, spiralling over several turns for long scrolls; with repeat they make a border. This works on the carve page too.
- Crops can be sectors, polygons, circles or a picture mask, and several can be combined.
- Models use real parallax or a transform animation, scale each axis, and have one handle to move, turn and size them.
- The lamp is placed by angle, radius and height. Its glare band is hatched on the disc, and the places that suit the selected model or picture are shaded violet.
- The update prompt shows this release's notes, in the app's language.
- The hologram page's experimental tools are gone.
